# プロジェクト設定

## 言語
- すべてのコミュニケーションは日本語で行う
- コードコメントは日本語で書く
- 変数名・関数名は英語
- コミットメッセージは日本語

## コーディング規約
- TypeScript を使用（.ts / .tsx）
- ESLint + Prettier でフォーマット
- インデント: スペース 2 つ
- セミコロン: あり
- 文字列: シングルクォート

## ファイルエンコーディング
- 新規ファイルは UTF-8 で作成
- 既存の Shift_JIS ファイルは sjis-guard フックが自動処理
- .csv ファイルは Shift_JIS の可能性があるため注意

## Git ルール
- main ブランチへの直接コミットは禁止
- コミットメッセージの形式: `type: 説明`
  - feat: 新機能
  - fix: バグ修正
  - docs: ドキュメント
  - refactor: リファクタリング
  - test: テスト
- .env ファイルはコミットしない
- CLAUDE.md はコミットしない

## テスト
- テストフレームワーク: Vitest
- テストファイル: `*.test.ts` / `*.test.tsx`
- テスト実行: `npm test`
- コミット前にテストが通ることを確認

## プロジェクト構造
```
src/
├── components/    ← UI コンポーネント
├── hooks/         ← カスタムフック
├── lib/           ← ユーティリティ
├── pages/         ← ページ
├── styles/        ← スタイル
└── types/         ← 型定義
```

## 依存パッケージ
- 新しいパッケージを追加する前に必ず確認する
- package-safety フックが不明なパッケージをブロックする
- 信頼リストへの追加: `~/.claude/jp-starter/trusted-packages.json`
